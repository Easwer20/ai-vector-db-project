
# AI Vector Database Project

This project demonstrates how to build a simple AI vector database pipeline using:

- PostgreSQL
- pgvector
- LangChain
- Hugging Face Embeddings
- Python

## Features

- Generate text embeddings using Hugging Face models
- Store vector embeddings in PostgreSQL using pgvector
- Learn semantic search and vector database concepts
- Understand the basics of Retrieval-Augmented Generation (RAG)

## Technologies Used

- Python
- PostgreSQL
- pgvector
- LangChain
- Hugging Face
- psycopg2

## Project Workflow

1. Connect to PostgreSQL database
2. Generate embeddings from text
3. Store embeddings inside pgvector
4. Retrieve vectors for semantic similarity tasks
